# Zombie SEZR — Raw Simulation Data

## IMPORTANT: These files are SYNTHETIC simulation outputs, NOT real observations.

These CSV files were generated by the original Math 36500 SEZR simulation model.
They are retained here for provenance (demonstrating the source of the prior
hyperparameters used in zombie_sezr_prior_params.json) but are NEVER read by
any BHMM script.

The BHMM uses ONLY zombie_sezr_prior_params.json as prior hyperparameter
specifications — not these raw files.

| File | Contents | Used in BHMM? |
|------|----------|----------------|
| sezr_initial_population.csv | Synthetic 1,500-person population | NO |
| sezr_person_day_observations.csv | Synthetic daily state counts | NO |

Source: Math 36500 assignment, v2 simulation parameters.
